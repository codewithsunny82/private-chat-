Two people. Encrypted messages. No message history on the server.

Not connected

Both people must use the same room code. Anyone who learns the code may try to join before the room is full, so use a long, random code and share it through a separate trusted channel.

Waiting for the other person…

Messages are encrypted in your browser with the recipient’s public key before transmission. This starter does not verify identities with fingerprints or safety numbers.

Security note: this is a learning starter, not a security-audited messenger. Deploy only over HTTPS/WSS. A compromised device, malicious modified website code, or an intercepted identity key can still expose messages.
